# Обнаруженные дефекты

## Потеря ссылки на асинхронную задачу удалённого исполнителя

20 ноября 2026 года запрос через публичный MCP с действующей учётной записью выполнил команду на удалённом участнике, но `mcp.tasks.start` вернул `task_receipt_unavailable`. Все три проверяемые ноды в этот момент работали. В журнале физического владельца сохранились завершённая задача и ожидаемый stdout. Синхронный `mcp.call` на том же участнике вернул результат.

Для воспроизведения подключиться к писателю, вызвать `mcp.inspect` для `shell_exec` другого участника и создать через `mcp.tasks.start` задачу с уникальной строкой вывода. Сверить ошибку клиента с квитанцией у владельца по этой строке. Повторная отправка выполнит команду ещё раз. Место проверки квитанции — `go-hub/internal/hub/code_mode_tasks.go`, метод `createdTask`.

## Публикация пакета Node с ранее выпущенной версией

Публичная сборка от 16 ноября 2026 года прошла Product CI. Следующий workflow `Publish verified Node release` завершился на шаге `Check for an unpublished Node version`. Исходники пакета изменились после публикации версии 1139, а файл `VERSION` по-прежнему содержит 1139. Воспроизводится проверкой версии для той же ревизии публичного зеркала.
