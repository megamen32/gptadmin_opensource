# Публикация упрощённой документации в main

## Запрос

«делай на main ветку в обоих репо».

## Цель

Интегрировать одобренный коммит документации Custom GPT/virtual MCP в `main`
репозитория GPTAdmin и синхронизировать `main` сайта, не включая посторонние
изменения рабочего дерева.

## Canary

Оба удалённых `origin/main` указывают на опубликованные коммиты; документационный
контрактный тест остаётся зелёным после интеграции.

## Scope

Только merge/cherry-pick уже опубликованного docs-коммита и fast-forward сайта.

## Exclusions

Не включать архивы, временные каталоги, task-файлы других агентов и изменения
производственного кода.

## Estimate

Initial active estimate: 15 minutes.
