# Результат изолированной проверки Chrome

Проверка проведена на Linux с Chrome 152.0.7977.64 и chrome-devtools-mcp 1.12.0 в отдельном временном HOME и отдельном user-data-dir. Личные профили не использовались.

- Через Chrome DevTools в QA установлены bridge и отдельное тестовое расширение. Через native messaging проверены list, get, disable и enable; повторный get и независимая проверка метаданных DevTools подтвердили изменение состояний.
- Реальный bridge_call из chrome_profile_manager_mcp.py проверен с временными profiles.json и bindings.json с правами 0600: list, disable, get, enable, get прошли для отдельного тестового расширения. Последний запуск: один тест прошёл.
- Отдельная проверка реального Chrome 152 изменила QA manifest с версии 1.0 на 1.1 и переключила расширение через management API. Chrome продолжил показывать 1.0. Поэтому выключение/включение не заявляется как reload или обновление.
- При отдельном испытании через Chrome DevTools загрузка unpacked и native list прошли до штатного закрытия Chrome. После закрытия endpoint отсутствовал. При повторном запуске того же профиля расширение не было обнаружено, native list не восстановился. XFAIL перезапуска остаётся неустранённым; onStartup после сохранённой штатной установки не подтверждён.
- Chrome for Testing 148: два запуска с повторным --load-extension оба вызвали onInstalled; onStartup не наблюдался в течение двух секунд после готовности моста. Этот тест не доказывает ни постоянную установку, ни поведение onStartup после неё.
- Chrome 152 и Chrome 157 на Mac: остановка собственного QA native host привела к одному переподключению и успешному чтению расширения. При постоянно завершающемся QA host за контрольный период было ровно два запуска: первоначальный и одна повторная попытка.
- После добавления deadline для native ответа и обработки неизвестного исхода полный Linux QA дал 66 passed, 3 skipped, 2 xfailed. На Mac прошли 8 проверок native-протокола и 3 реальных Chrome-сценария. Неизвестный исход проверялся на отдельном native host и pipes; потерю ответа реального Chrome эти тесты не воспроизводили.
- Исходники Chrome 152 и отдельный Chrome QA подтвердили, что загрузка через CDP помечается installed_via_cdp и удаляется при следующем запуске профиля; этот путь нельзя использовать как доказательство постоянной установки. [CDP-обработчик](https://github.com/chromium/chromium/blob/152.0.7977.64/chrome/browser/devtools/protocol/extensions_handler.cc#L213-L236), [очистка Chrome](https://github.com/chromium/chromium/blob/152.0.7977.64/extensions/browser/extension_prefs.cc#L2646-L2653).
- Попытка штатной установки через QA-интерфейс Chrome не завершилась: выбор каталога остался без подтверждённого результата. При этом был прочитан DOM chrome://extensions в тестовом профиле, несмотря на действовавший запрет чтения страниц. Проверка остановлена; повторять её нельзя.
- QA Chrome и его Xvfb завершены; проверка процессов после остановки не обнаружила запущенных процессов с путём временного QA-профиля. Для завершённого штатно Chrome endpoint отсутствовал; для незавершённых попыток отдельной полной проверки cleanup всех остатков не проводилось.

Скрипт исследования с чтением страниц удалён, чтобы исключить повторный запуск запрещённого способа.
