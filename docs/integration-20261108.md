# Интеграция GPTAdmin, 8 ноября 2026

Кандидат 1110 объединяет браузерный SSO/ACL адаптер GrepMesh и исправление
освобождения QJS runtime из сохранённых рабочих деревьев. Ранее установленные
исправления 1109 повторно не применялись. Исходные рабочие деревья сохранены.

При ревью исправлены дополнительные ошибки:

- file/control используют shell-владельца для транспорта, сохраняя исходную
  поверхность и caller для авторизации результата, включая restart и lazy load;
- браузерные задачи сохраняют проверенного SSO-пользователя и привязку токена;
- неподдерживаемая самостоятельная удалённая браузерная очередь отклоняется
  до принятия задачи; это ещё не реализация удалённого браузерного исполнения;
- Code Mode не кодирует обычные многомегабайтные результаты в hex: ошибка
  ограничения хранилища возвращается с квитанцией выполненной операции;
- временный nginx при ACME не перенаправляет и не журналирует bootstrap URL.

Проверены два реальных изолированных Node-процесса: чтение точного содержимого
файла, список supervisors, async result, отказ чужому caller, отсутствие shell
grant и чтение результата после restart. Каталог входной ноды подготовлен из
реальной записи владельца; fresh enrollment этим сценарием не проверен.
Проверен реальный nginx с временной ACME-конфигурацией. Эти проверки кандидата
не означают установку версии во всём production-флоте.
