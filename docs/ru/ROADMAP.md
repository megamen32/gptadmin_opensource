## Приоритеты MCP и источников контекста — 08.11.2026

Запланировано, ещё не выпущено. Продолжение текущего GPTAdmin fullcycle;
Remote Node SSH/Telnet остаётся на паузе.

1. **Схемы активных MCP в меню ресурсов:** краткий каталог, схемы отдельных
   серверов и опциональный полный снимок. Содержимое загружается по запросу;
   права проверяются при перечислении и чтении. Показывать размер, свежесть и
   неполноту снимка. Проверка — выбор ресурса в настоящем клиенте без загрузки
   всех схем при простом открытии списка.
2. **Источники контекста дочерних MCP:** ресурсы, шаблоны, чтение и поддерживаемые
   уведомления; стабильные URI без коллизий. Выбор источников в профиле и при
   создании ссылки в пределах выданных прав. Проверка — переподключение,
   обновление, одинаковые URI у разных детей и отзыв доступа.
3. **Расширенная поддержка современного MCP («MCP 2.0»):** матрица возможностей
   по датированным версиям и согласованным расширениям, начиная с 2026-07-28;
   ресурсы, пагинация, уведомления, кэширование, структурированные ответы,
   задачи и совместимость клиентов. Недостающее — через TDD и реальную
   потребительскую проверку; измерять расход контекста.

По стандарту ресурсы управляются приложением-клиентом: оно решает, предложить
выбор человеку или загрузить содержимое автоматически. Публикация ресурса
не означает автоматическую вставку всех схем в каждый запрос. После добавления
содержимое может расходовать токены. Схема как ресурс сама по себе не подключает
инструмент и не выдаёт право его выполнять.

- **ShellMCP** (Go + Python) — агент для Linux/macOS/Windows.

- **Туннели** — автотуннель FRP + Cloudflare
- **Веб-панель** (`/admin`) — очередь, состояние агента, журналы.
- **OAuth** для OpenAI SDK.
- **Установка скриптов** для Linux/macOS/Windows (пользовательский + системный режим)
- **Фоновые задачи** с опросом
- **Усечение вывода** (сохраняет токены)
- **Управляемые резервные копии файлов** с TTL.

## Модель с открытым ядром

GPT‑Админ является **открытым** в соответствии с AGPL-3.0.

### Бесплатно навсегда (этот репозиторий)

- Хаб, шеллмкп, все три адаптера
- Базовая веб-панель (очередь, работоспособность, журналы)
- Все команды CLI
- Все туннели
- Поддержка сообщества (проблемы GitHub, обсуждения)

### Будет платным (отдельный репо/облако)

- Хостинг-облако (управляемый хаб, без самостоятельного хостинга)
- Корпоративный единый вход (SAML/OIDC) + SCIM
- Расширенный RBAC (роли, разрешения для каждого агента)
- Расширенный журнал аудита + экспорт SIEM
- SLA + приоритетная поддержка
- Расширенная панель (панели мониторинга команды, оповещения, аналитика)

Ядро остается открытым. Платные функции являются аддитивными — платного доступа не существует.
функциональность.

## Управление версиями

Мы следуем [SemVer](https://semver.org/). См. [историю выпусков](../CHANGELOG.md)
для истории выпусков.

- `0.x` — до 1.0, возможны критические изменения между второстепенными версиями.
- `1.0` — первая стабильная версия (после выпуска веб-панели)
- `1.x+` — дополнения с обратной совместимостью.
