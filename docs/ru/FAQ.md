# Часто задаваемые вопросы

## GPT‑Админ бесплатен?

Да. Ядро (хаб, шеллмкп, все три адаптера, базовая веб-панель) бесплатное.
навсегда под AGPL-3.0. Будущие платные предложения (размещенное облако, корпоративный единый вход,
расширенная панель) будет аддитивной — мы не будем платить за существующие функции.
См. [План действий](./ROADMAP.md).

## Нужна ли мне платная подписка на AI?

Нет. Расширение браузера работает с **бесплатными веб-чатами** — DeepSeek, Qwen,
Яндекс Алиса, Сбер ГигаЧат, даже бесплатный ChatGPT. См.
[Адаптеры → Расширение для браузера](./ADAPTERS.md#2-browser-extension).

## Безопасно ли предоставлять ИИ доступ к моим серверам?

GPT‑Админ предназначен для этого. Основные функции безопасности:

- **Пользовательский режим по умолчанию** — root/sudo не требуется.
- **Список разрешенных команд** — ограничивает возможности ИИ.
- **Режим утверждения** — подтверждение критически важных операций человеком.
- **Журнал аудита** — каждая команда записывается с указанием вызывающего абонента + результата.
- **Секреты скрыты** в журналах.
- **Управляемое резервное копирование** перед редактированием файлов.

См. [Безопасность](./SECURITY_DOCS.md).

## Будет ли ИИ выполнять команды без моего ведома?

Нет. Команды выполняются только тогда, когда вы спрашиваете в чате. Для критических операций
(удаления, изменения в сети), режим утверждения требует подтверждения человеком.

## В чем разница между тремя адаптерами?

Тот же центр, те же возможности — это просто разные способы для ИИ.
подключить:

- **Клиент MCP** — для Claude/Codex/OpenCode (встроенная поддержка MCP)
- **Расширение для браузера** — для бесплатных веб-чатов (API не требуется)
- **Действие OpenAI** — для ChatGPT Пользовательский GPT/Открытый веб-интерфейс

См. [Адаптеры](./ADAPTERS.md).

## Как обрабатываются учетные данные?

Вы помните только `AdminPassword`. Хаб создает кратковременные области видимости
Соединения OAuth для клиентов MCP и управление учетными данными устройства агента в
конфигурация сервиса. Обычная установка никогда не просит вас скопировать внутренний ключ.

## `/mcp` возвращает 401 — почему?

`/mcp` требует подключения OAuth с ограниченной областью действия. Снова откройте страницу подключения хаба и
завершить поток OAuth; Клиенты MCP обрабатывают соединение автоматически. Для
локальная разработка, хаб может ослабить авторизацию на локальном хосте. См. [Конфигурация →
OAuth](./CONFIGURATION.md#oauth).

## Нужен ли мне собственный домен?

Нет. Установщик предлагает автоматический туннель через FRP — вы получаете общедоступный URL-адрес на
`frp.bezrabotnyi.com` без настройки DNS. Для вашего собственного домена используйте Cloudflare.
Туннель или nginx + Certbot. См. [Туннели](./TUNNELS_DOCS.md).

## Работает ли это в Windows?

Да. Агент запускается в Windows (пользовательский режим, администратор не требуется) через
Запланированная задача. Установить с помощью:

```powershell
iwr -UseBasicParsing https://became.bezrabotnyi.com/install_win.ps1 | iex
```

См. [Пути установки](./INSTALL_PATHS.md).

## Могу ли я использовать его без расширения браузера или пользовательского GPT?

Да — используйте адаптер **MCP client** с Claude Desktop, Codex или OpenCode.
Они подключаются напрямую через удаленный SSE MCP, браузер не требуется. См.
[Адаптеры → Клиент MCP](./ADAPTERS.md#1-mcp-client).

## Как работает усечение вывода?

Длинный стандартный вывод/stderr разбивается на фрагменты (по умолчанию: 1 МБ). ИИ видит голову + хвост +
указатель «читать дальше». Это экономит токены — ИИ читает только то, что ему нужно.
ответить. См. [Справочник API → Усечение вывода](./API_REFERENCE.md#output-truncation).

## Могу ли я подключить другие MCP?

Да! Хаб может использовать другие серверы MCP (chrome-devtools для веб-поиска,
openmemory для памяти проекта и т. д.) и предоставлять их в качестве инструментов каждому
подключенный ИИ. См. [Архитектура](./ARCHITECTURE.md).

## Как вращать жетоны?

См. [Безопасность → Ротация токенов](./SECURITY_DOCS.md#token-rotation). Краткая версия:
сгенерируйте новые значения с помощью `openssl rand -hex 32`, обновите среду хаба, перезапустите,
обновлять клиентов.

## Что-то сломалось. Где логи?

- Концентратор: `journalctl -u gptadmin_hub -n 100` (или `--user` для пользовательского режима)
- Агент: `journalctl -u shellmcp -n 100` (или `--user`)
- Или прочитайте их в веб-панели: `/admin` → Журналы.

## Как удалить?

```bash
gptadmin uninstall
```

Удаляет двоичные файлы, конфигурации и сервисные модули. Резервные копии файлов сохраняются.
