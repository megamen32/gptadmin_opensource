# Концентратор (`go-hub/`)

Хаб — это центральный процесс GPT‑Админ. Он передает команды от ИИ на
агенты Shellmcp, обрабатывают аутентификацию и обслуживают веб-панель.

## Что он делает

1. **Регистрирует агенты** — агенты Shellmcp отправляют контрольные сигналы на `POST /heartbeat`;
   хаб отслеживает их и отмечает в автономном режиме, если пульс прекращается.
2. **Команды маршрутизации** — когда ИИ вызывает инструмент, хаб ищет цель.
   агент и пересылает команду.
3. **Аутентификация** — `AdminPassword` для администрирования человеком, OAuth для
   Клиенты MCP и подключения управляемых устройств для агентов.
4. **Обрезает вывод** — длинный стандартный вывод/stderr разбивается на части для сохранения токенов (ИИ
   Подробнее можно прочитать по запросу).
5. **Обслуживает панель** — веб-интерфейс по адресу `/admin` (очередь, работоспособность агента, журналы).
6. **Открывает MCP** — удаленный SSE MCP по адресу `/mcp` для клиентов MCP.
7. **Открывает реле OpenAPI** — канонический импорт пользовательского GPT в `/actions/openapi.yaml`; при импорте на каждый сервер используется `/server/{slug}/actions/openapi.yaml`.
8. **Принимает веб-перехватчики** — аутентифицированный вход `/webhooks/v1/{route}` передает отдельный отключенный по умолчанию виртуальный MCP `webhooks` и может отправлять настроенный MCP, приглашение или действие оболочки.

## Удаленный секретный доступ

Авторизованный клиент MCP с полным доступом может вызвать `secret_request` с меткой
и необязательный `env_name`. Концентратор возвращает непрозрачный `secret_ref` и короткий
жил одно время `input_url`; он никогда не возвращает токен отдельно и не принимает
значение в MCP JSON. Откройте `input_url` в браузере, отправьте значение один раз, затем вызовите
`secret_status` для подтверждения `ready` без получения открытого текста.

Чтобы использовать значение в задании управляемой оболочки, передайте только ссылку:

```json
{
  "target": "shell:example",
  "tool": "shell_exec",
  "args": {
    "cmd": "printenv EXAMPLE_TOKEN",
    "secret_env": {"EXAMPLE_TOKEN": "secret-ref-from-secret_request"}
  }
}
```

Хаб разрешает эталонную серверную часть и вводит ее только в утвержденный
задание и удаляет его из результатов MCP, проверки задания, записей аудита и журналов.
Профили только для чтения не могут запрашивать или проверять секреты. Метаданные `file` представляют собой
непрозрачная ссылка на хранилище, управляемое Hub, а не разрешение на чтение файла
`system_inspect`. Публичный маршрутизатор сохраняет существующий источник концентратора и не
выставьте внутренний маршрут 2.1.

## Бег

```bash
python3 cli.py setup --hub --tunnel none --user
```

По умолчанию он прослушивает `0.0.0.0:25900`. Измените его с помощью `--port` или `HUB_PORT`.

## Ключевые конечные точки

| Конечная точка | Авторизация | Цель |
|----------|------|---------|
| `GET /admin` | Сеанс администратора | Веб-панель |
| `GET /admin/api/*` | Сеанс администратора | REST API администратора |
| `POST /mcp` | Носитель OAuth | Удаленный SSE MCP (для клиентов MCP) |
| `POST /heartbeat` | Подключение управляемого устройства | Регистрация агента |
| `GET /servers` | Сеанс администратора | Список зарегистрированных агентов |
| `GET /actions/openapi.yaml` | нет | Каноническая схема OpenAPI для пользовательского импорта GPT |
| `GET /api.json` | нет | Устаревший псевдоним JSON для схемы реле |
| `GET /openapi.yaml` | нет | Устаревший псевдоним YAML для схемы реле |
| `POST /oauth/authorize` | `ADMIN_PASSWORD` форма | Конечная точка авторизации Canonical OAuth |
| `POST /webhooks/v1/{route}` | Маркер маршрута или подпись HMAC | Универсальный вход событий |
| `GET /webhook-jobs/{job_id}` | Те же данные маршрута | Прочитать статус/результат задания вебхука |
| `GET/POST /webhook-routes` | Аутентификация управления хабом | Перечислите или создайте определения маршрутов без возврата секретов |
| `PUT/DELETE /webhook-routes/{route}` | Аутентификация управления хабом | Заменить или удалить маршрут, принадлежащий оператору |
| `POST /oauth/token` | учетные данные клиента | Конечная точка токена Canonical OAuth |
| `GET/POST /secret-input/{token}` | Одноразовый токен браузера | Введите секретное значение один раз; ответы никогда не включают это |

Подробную информацию см. в [Справочнике по API](./API_REFERENCE.md)].
См. [Webhooks](./WEBHOOKS.md)] для настройки маршрута и семантики доставки.

## Срок действия учетных данных OAuthКоды авторизации OAuth и обмен обновлениями используют JWT кратковременного доступа и
непрозрачные, периодически обновляемые учетные данные. Хаб сохраняет только дайджест
обновить учетные данные; он выдержит перезапуск Хаба в течение пяти календарных лет, если только
явно отозван. Клиенты должны сохранить замещающее значение, возвращаемое каждым
обновить. Управляемые ключи носителя MCP также выдаются без явного `ttl_days`.
по умолчанию пять лет. Существующие строки JWT сохраняют подписанное время жизни и
никогда не заменяются автоматически обновлением.

## Веб-панель (`/admin`)

Откройте URL-адрес хаба, напечатанный программой установки, и выберите **Администратор**. Войдите под своим
`AdminPassword`. Вы увидите:

- **Очередь** — активные и выполненные задачи на агента (статус, время, результат)
- **Состояние агента** — список агентов Shellmcp + подключенных MCP (openmemory,
  chrome-devtools, …) с онлайн-/оффлайн-статусом
- **Журналы** — журнал команд и выходные данные, доступные для чтения из браузера (без SSH).

## Надзор

Хаб Go контролируется непосредственно systemd с помощью `Restart=always`. Устаревшие сторожевые блоки Python были удалены. Перезапустите вручную:

```bash
systemctl restart gptadmin-hub.service
```
