# ШеллMCP

ShellMCP — это агент, который работает на каждой целевой машине. Он регистрируется в
концентратор, выполняет команды локально и возвращает реальный результат.

## Что он делает

- **Регистрируется** в Hub через подключение управляемого устройства.
- **Выполняет** команды оболочки, файловые операции, действия systemd.
- **Возвращает** реальный стандартный вывод/stderr (концентратор обрезает длинный вывод для сохранения токенов)
- **Запускается** в пользовательском режиме по умолчанию (без sudo), в системном режиме при необходимости.
- **Работает** на Linux, macOS, Windows.

## Реализации

| Осуществить | Статус | Местоположение | Когда использовать |
|------|--------|----------|-------------|
| Перейти (`go-shellmcp/`) | **Основной (только)** | `go-shellmcp/` | Новые развертывания — быстрее, один двоичный файл |

> **Примечание.** Устаревшие реализации Python (`client/shellmcp*.py`) удалены
> из дерева исходников. Все инсталляции теперь используют Go-бинарь `shellmcp-go`.

## Установить на целевую машину

```bash
# Linux / macOS (installs the Go binary in user-mode by default)
curl -s https://became.bezrabotnyi.com/install.sh | bash
```

Установщик:
- Режим автоматического определения: нет sudo → пользовательский режим (`~/.local/share/gptadmin`),
  с помощью sudo → системный режим (`/opt/gptadmin`)
- Регистрирует пользовательскую службу (`systemctl --user` в Linux, `LaunchAgents` в macOS)
  - Печатает URL-адрес хаба и имя агента; учетные данные подключения остаются под управлением
    установщик и сервис

## Запуск вручную

Для ручной настройки только агента запустите `gptadmin setup --no-hub --shellmcp` и
при появлении соответствующего запроса заполните страницу подключения к концентратору. Не копируйте сервис
учетные данные в терминал или чат.

## Переменные среды

| Вар | Требуется | По умолчанию | Цель |
|-----|----------|---------|---------|
| `HUB_URL` | да | — | URL-адрес хаба для регистрации |
| `SHELLMCP_NAME` | нет | имя хоста | Имя агента отображается в хабе |
| `SHELLMCP_LISTEN` | нет | 25901 | Локальный порт прослушивания |
| `EXEC_TIMEOUT` | нет | 120 | Максимальное время выполнения команды (секунды) |
| `LOG_LIMIT_B` | нет | 65536 | Максимальное количество встроенных значений stdout/stderr, возвращаемых этим агентом ShellMCP, прежде чем полный поток будет помещен в буфер на диск (в байтах) |

`LOG_LIMIT_B` — для каждого агента ShellMCP. Он контролирует локальный хвост результата `/exec` и не заменяет бюджеты ответов концентратора/клиента; концентратор по-прежнему может применять разные бюджеты ответов для действий ChatGPT, Claude или других клиентов MCP.

## Операции раскрыты

Хаб передает их агенту. Доступно для всех 3 адаптеров:

| Операция | Пример |
|-----------|---------|
| `shell_exec` | запустите команду оболочки, верните stdout/stderr |
| `file_read` | прочитать файл |
| `file_write` | записать файл (с резервной копией) |
| `file_backup` | создать управляемую резервную копию перед редактированием |
| `systemd_*` | статус/старт/стоп/перезапуск/включение агрегатов |
| `system_info` | ЦП, ОЗУ, диск, время безотказной работы |
| `system_health` | быстрая проверка здоровья |
| `venv_*` | управлять виртуальными средами Python |
| `dir` | список каталогов |

Точную схему см. в [Справочнике API](./API_REFERENCE.md)].

## Безопасность

- Агент принимает только подключение своего управляемого устройства.
- По умолчанию запускается от имени устанавливающего пользователя (не root) — системный режим с sudo
  является добровольным
- Можно настроить список разрешенных IP-адресов и список разрешенных команд.
- Секреты маскируются в журналах

См. [Безопасность](./SECURITY_DOCS.md).
