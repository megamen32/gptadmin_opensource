# адаптеры

Хаб предоставляет **три способа** подключения ИИ. Тот же концентратор, те же возможности
— выберите тот, который соответствует вашему ИИ.

| Адаптер | Для | Как |
|---------|-----|-----|
| [Клиент MCP](#1-mcp-client) | Клод Рабочий стол, Кодекс, OpenCode | Удаленный SSE MCP в `/mcp` |
| [Расширение браузера](#2-browser-extension) | DeepSeek, Qwen, Алиса, GigaChat, ChatGPT (бесплатно) | пользовательский скрипт (Tampermonkey/Firefox) |
| [Действие OpenAI](#3-openai-action) | ChatGPT Пользовательский GPT, открытый веб-интерфейс | сгенерированная схема OpenAPI; выберите Носитель или OAuth |

## 1. Клиент MCP

**Для:** Claude Desktop, Codex, OpenCode, любого клиента, совместимого с MCP.

**Протокол:** удаленный SSE MCP (поточный HTTP).

**Конечная точка:** `https://your-hub.bezrabotnyi.com/mcp` (найдите ее в `/connect`)

### Настройка

Добавьте концентратор в качестве сервера MCP в конфигурацию вашего клиента. Для Claude Desktop отредактируйте
`claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "gptadmin": {
      "type": "http",
      "url": "https://your-hub.example/mcp"
    }
  }
}
```

Для Codex/OpenCode одна и та же конфигурация находится в соответствующих настройках MCP.

Перезапустите клиент. Вы должны увидеть инструменты `gptadmin` (shell_exec, file ops,
systemd и т. д.).

### Примечания

- `/mcp` использует код авторизации OAuth + PKCE. Начните с `/connect` или
  `/.well-known/oauth-authorization-server` метаданные; внутренние значения носителя
  никогда не копируются в конфигурацию клиента. См.
  [Конфигурация → OAuth](./CONFIGURATION.md#oauth).
- Для локальной разработки используйте тот же поток OAuth для концентратора обратной связи.

### Срок действия авторизации

Клиент MCP, прошедший авторизацию, должен сохранить достаточное количество управляемых клиентом
состояние сеанса, чтобы обновить или восстановить эту авторизацию, не запрашивая
оператор, чтобы повторить настройку. В частности, перезапуск коннектора, перезапуск клиента,
или обычный путь обновления токена не должен оставлять за собой настроенный иначе GPTADMIN.
соединение не может вызвать `discover`.

Если Кодекс сообщает `reauthentication_required` или об отсутствии состояния обновления, используйте
контроль повторного подключения клиента один раз для восстановления доступа; не вклеивайте внутренние
Учетные данные хаба в клиенте. Рассматривайте сообщение как жизненный цикл соединителя.
дефект до тех пор, пока не будет идентифицирован слой-владелец. Прежде чем развертывать связанное исправление,
проверьте новую авторизацию, определенный сценарий перезапуска/обновления и реальный
безобидное `discover -> schema -> execute` взаимодействие. Требуемые доказательства – это
указанный в [Контракте управления интеграцией](./INTEGRATION_CONTROL_CONTRACT.md#authorization-durability).

## 2. Расширение для браузера

**Для:** DeepSeek, Qwen, Яндекс Алиса, Сбер GigaChat, ChatGPT (уровень бесплатного пользования) —
любой бесплатный веб-чат.

**Протокол:** пользовательский скрипт (запускается в браузере через Tampermonkey/Firefox).

**Установить:** https://became.bezrabotnaya.com/mcp-bridge.user.js

### Как это работает

Пользовательский скрипт добавляет в пользовательский интерфейс веб-чата две кнопки:
- **MCP All** (`Alt+M`) — вставляет компактное описание всех ваших агентов MCP.
  и их инструменты для ввода в чат. Также копирует приглашение в буфер обмена.
- **MCP** — открывает панель для выбора конкретного агента с подробной документацией по инструменту.

Когда ИИ отвечает блоком кода ` ```mcp `, содержащим команду JSON,
скрипт автоматически:
1. Выделяет блок
2. Отправляет вызов на ваш хаб.
3. Вставляет результат обратно в чат

### Настройка для каждой платформы

| Платформа | Менеджер | Шаги |
|----------|---------|-------|
| macOS/Windows/Линукс | Chrome + [Tampermonkey](https://www.tampermonkey.net/) | Установите Tampermonkey из Интернет-магазина Chrome, затем нажмите ссылку установки. |
| айфон | Safari + [Пользовательские скрипты](https://apps.apple.com/app/userscripts/id1463298887) | Установите приложение Userscripts, включите его в Safari → Расширения, затем установите. |
| Андроид | Firefox + Тампермонки | Установите Firefox из Google Play, добавьте Tampermonkey, затем установите. |

### Конфигурация

Нажмите `Alt+K` (или значок ключа в правом нижнем углу) и введите:
- **URL-адрес моста** — URL-адрес вашего хаба (`https://your-hub.bezrabotnyi.com`)
– Завершите однократное соединение `/connect`/поток OAuth; не вставляйте внутренний
  Учетные данные хаба или агента в расширении браузера.

### Поддерживаемые сайты| Сайт | Статус |
|------|--------|
| чатgpt.com | Полная поддержка |
| чат.deepseek.com | Полная поддержка |
| чат.qwen.ai | Полная поддержка |
| ya.ru / чат.yandex.ru | Полная поддержка |

> Если автовставка не работает (редко, на некоторых сайтах), подсказка всегда отображается
> ваш буфер обмена — просто `Ctrl+V` / `Cmd+V`.

## 3. Действие OpenAI

**Для:** ChatGPT Пользовательский GPT, открытый веб-интерфейс.

**Протокол:** REST + сгенерированная схема OpenAPI. Пользовательские действия GPT используют
URL-адрес схемы, которую вы импортируете; Вместо этого собственные клиенты MCP используют `/mcp`.

**URL-адреса схем:**

– Для всего концентратора: `https://your-hub.example/actions/openapi.yaml`
- Один сервер: `https://your-hub.example/server/{slug}/actions/openapi.yaml`

Хаб генерирует эти схемы из текущего списка инструментов MCP. Импортируйте URL-адрес
вам нужно; не редактируйте вручную схему пользовательского тега GPT.

### Настройка (пользовательский GPT ChatGPT)

1. Откройте https://chatgpt.com/gpts/editor.
2. Создайте или отредактируйте GPT → Настроить → Действия → Создать новое действие.
3. Импортируйте OpenAPI по URL-адресу: `https://your-hub.example/actions/openapi.yaml`.
   Это сгенерированная схема всего концентратора. Для одного сервера импортируйте
   Вместо этого `/server/{slug}/actions/openapi.yaml`.
4. Выберите путь авторизации:

   - **Носитель** — выберите **Ключ API** → **Носитель**, затем вставьте только ограниченную область действия.
     стоимость токена, выпущенного Хабом.
   - **OAuth** — выберите **OAuth**, затем используйте поток авторизации/токена Hub из
     URL-адрес хаба.

Носитель — это кратчайший путь, когда GPT нужен только токен с ограниченной областью действия. OAuth — это
лучший выбор, если вы хотите, чтобы GPT проходил через процесс входа в Hub.

5. Сохраните и используйте элемент управления **Тест** для каждой операции. Первый звонок открывается
   Одноразовое подтверждение исходящего вызова ChatGPT; утвердите его, затем подтвердите
   сгенерированная схема работает с безобидным действием.

### OAuth для пользовательского GPT

Пользовательский GPT OAuth использует поток кода авторизации. Выберите **OAuth** в
Диалоговое окно аутентификации действий и настройка публичного хаба:

- URL авторизации: `https://your-hub.example/oauth/authorize`;
- URL-адрес токена: `https://your-hub.example/oauth/token`;
- идентификатор клиента: стабильная метка для этого GPT (например, `chatgpt-custom-gpt`);
- области действия: `gptadmin.read` (добавьте `gptadmin.exec` только при необходимости).

ChatGPT предоставляет обратный вызов. Некоторые версии пользовательского редактора GPT не отправляют
Параметры PKCE, поэтому концентратор принимает этот совместимый код авторизации.
вариант только для точного `https://chat.openai.com/aip/g-.../oauth/callback`
профиль обратного вызова. Любой другой клиент OAuth должен использовать PKCE S256.
На странице авторизации Hub войдите в систему и завершите перенаправление, затем запустите
снова безобидное тестовое воздействие. Хаб отклоняет токен, эмитент, аудитория которого
идентификатор ресурса, подписи или ключа не соответствует его каноническому общедоступному происхождению.

### Диагностируйте ошибку 401, не раскрывая учетные данные

Запустите приведенную ниже команду в той же установке, на которой работает Hub. Он печатает
только пути конфигурации, нормализованный эмитент/аудитория/ресурс, ключ подписи
отпечаток пальца и четкий местный приговор; он никогда не печатает предоставленный JWT или
секрет подписания.

```bash
gptadmin auth-diagnose --token '<paste-token-here>'
```

Для токена, который работает с общедоступным URL-адресом, но не с обратной связью (или наоборот),
убедитесь, что настройки происхождения, ресурсов и подписи концентратора взяты из
тот же файл конфигурации, затем перезапустите этот концентратор и выдайте новый токен. Не
укажите пользовательский GPT в `127.0.0.1`.

### Настройка (открытый веб-интерфейс)

Добавьте хаб в качестве конечной точки инструмента/функции в настройках Open WebUI:
- URL: `https://your-hub.example/mcp-relay`
- Схема OpenAPI: импортируйте `https://your-hub.example/actions/openapi.yaml`.
- Аутентификация: scoped Bearer-токен либо OAuth Authorization Code + PKCE из
  метаданных Hub, если клиент поддерживает динамическую регистрацию.

### Почему «нет ограничений Кодекса»

Пользовательские действия GPT не имеют почасовых квот на вызовы инструментов, таких как Codex. Пока
ваш хаб включен, ChatGPT может вызывать его столько, сколько необходимо.

## Какой адаптер мне следует использовать?

- Используете **Claude Desktop/Codex/OpenCode** изначально? → **Клиент MCP**
- Хотите использовать **бесплатные веб-чаты** (Qwen, Alice, GigaChat)? → **Расширение для браузера**
– Вы используете **ChatGPT с Plus** и хотите использовать собственный GPT? → **Действие OpenAI**

Все три предоставляют одинаковые возможности — хабу не важно, какой адаптер
используемый ИИ. См. [Архитектура](./ARCHITECTURE.md), чтобы узнать, почему.
