# Subagents

## Brief template

You are a subagent. On any uncertainty or blocker, message the parent via `send_message`; state evidence, blocker, recommendation, and exact question. Do not broaden scope.

- Confirmed pre-fix evidence:
- Contract/examples:

- Handoff: assumptions; changed files; commands/results; risks; next action.

## Review checklist

- Diff only inside scope.
- Regression test was red, then green.
- Focused/subsystem evidence matches claim.
- No secrets, unrelated formatting, compatibility shim, or hidden fallback.
- Handoff has one actionable next step.
